# Career Targets & Scholarship Alignment

Target posisi dan kriteria spesifikasi yang dituju:

---

## Target 1: Software Engineer / Frontend Developer Intern
- **Perusahaan Target:** Tech unicorns, high-growth startups, agency digital terkemuka.
- **Kualifikasi Utama:**
  - Kemahiran mendalam pada TypeScript, React, Next.js, dan arsitektur UI berbasis komponen.
  - Pemahaman mendalam tentang state management, Web APIs, dan performa web (Core Web Vitals).
  - Keahlian slicing desain pixel-perfect dengan Tailwind CSS / CSS Variables serta aksesibilitas tinggi.
- **Selling Point Yashif:**
  - Pengalaman menangani real-time streaming data telemetri di GCS.
  - Pemikiran sistematis dari latar belakang QA.

---

## Target 2: Quality Assurance (QA) / Software Development Engineer in Test (SDET) Intern
- **Perusahaan Target:** Perusahaan SaaS, fintech, telekomunikasi.
- **Kualifikasi Utama:**
  - Automated testing (Playwright, Jest, Cypress).
  - Pembuatan test plan, test case traceability matrix, dan integrasi CI/CD pipelines.
- **Selling Point Yashif:**
  - Developer yang paham arsitektur kode frontend sehingga mampu menulis integration test yang presisi.

---

## Target 3: Robotics Telemetry & Ground Control Station (GCS) Engineer Intern
- **Perusahaan Target:** Industri dirgantara, drone manufacturer, riset pertahanan & maritim.
- **Kualifikasi Utama:**
  - Penanganan protokol MAVLink, WebSockets, serial connection, visualisasi geospasial & sensor IMU.
- **Selling Point Yashif:**
  - Pengalaman nyata di divisi GCS KRTI UNS (Narash BUV).

---

## Target 4: Beasiswa Prestasi & Riset Akademik
- **Target:** Beasiswa Unggulan, Djarum Beasiswa Plus, IISMA, atau Fast-track Research Grants.
- **Fokus Narasi:** Kolaborasi multidisiplin (Informatika + Robotika Dirgantara), kontribusi nyata pada tim nasional, integritas riset.
